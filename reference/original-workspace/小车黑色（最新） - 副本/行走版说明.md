# 纯行走版

2026-09-13 按要求从学长工程中精简。主控和库仍为 STM32F103ZE、标准外设库 V3.5.0、Keil ARM Compiler 5。

用户已确认底盘使用麦克纳姆轮。轮号对应的安装位置及各轮正方向仍需核对；car() 的 dir=5、6 保留原地旋转的两种相反方向，具体哪个对应左转或右转以实物为准。

## 现在运行什么

初始化四轮电机串口、姿态串口和朝向更新定时器后，执行一次原来首次视觉定位之前的两段行走：

1. `car(7, 500, 6000 * 4)`：2、3 号轮电机执行第一段运动。
2. `car(0, 0, 0)`：修正朝向到 0 度。
3. `car(1, 500, 16500 * 4)`：四轮执行第二段运动。
4. `car(0, 0, 0)`：再次修正朝向并停止，随后留在空闲循环。

现在不依赖扫码或摄像头，不会抓料、控制升降台或进入后续搬运路线。两段距离沿用原参数；实际停止位置仍取决于起点、轮子和电机配置。电机回复和姿态反馈仍是行走控制的依赖。
