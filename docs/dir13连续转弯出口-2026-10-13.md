# dir13：前直行、转弯、后直行（2026-10-13）

后续修复：用户实车报告转弯乱飘，以下旧版混用位置/速度模式的实现已替换。当前采用四轮统一速度模式前段/转弯、保留用户100ms稳定等待，再四轮统一位置模式执行后段。阶段、参数和验证见 [dir13统一四轮控制修复](dir13统一四轮控制修复-2026-10-13.md)。

用户要求在 dir12 后继续接 dir2，并确认取消中间 `car(0,-90,0)` 的停车调正，以连续运动衔接为主。

当前 C 盘 `BSP/task.c` 的 yuanliao 第一处调用改为：

```c
car(13,speed,11500*4-CAR_ARC_90_TRIM_PULSES);
```

它替换原 dir12、停车调正、50 ms 等待和随后的 dir2。该组合结束后，仍按原流程等待 100 ms，再执行第二处 dir10 转弯。其他路段、dir10/12 本身、串口、main 和舵机不变。

## 为什么不能继续只把脉冲相加

dir12 同速驱动四轮、左右目标距离不同，短程轮先结束后长程轮继续运动，产生转向。如果把转弯后的直行脉冲也直接加到四轮目标上，会延后短程轮停止，主要变成转弯前多走，不能证明是转弯后再直行。

dir13 改为运动中按现有陀螺仪角度切换，不进行中间停车调正。

## 执行过程

1. 1、3 号轮沿原 dir12 方向执行 `前直行脉冲 + 2225*4` 的位置运动。2、4 号轮沿原方向执行同速度的持续速度运动。起步加速度为 150，发送间隔保持 10 ms。
2. 连续累加现有 `anglea` 的角度变化，处理 ±180° 跨界。当同 dir6 方向累计转够 `CAR_DIR13_TURN_DEG` 时进入后直行阶段。期间不发送 car0、停止或电机状态查询。
3. 立即对四轮发送同向的后直行位置指令，速度仍为 speed，加速度参数使用 0，即协议定义的直接按目标速度运行，省去程序要求重新从零加速的过渡。发送仍有 10 ms 间隔，物理角度和电机过渡不可能保证没有误差。
4. 后直行末尾使用项目已存在的 WheelReply 字节解析器，收到四轮新的 FD 到位记录后返回。只在整个组合末尾等待到位，中间不等位置完成。没有新增 3A 状态查询和串口解析。

依据仓库 `reference/manuals/ZDT_X42S第二代闭环步进电机用户手册V1.0.5.pdf` 的 Emm 速度/位置模式指令及 acc=0 定义，并沿用当前工程 Emm_V5 接口的相对运动参数。实际驱动器模式切换接受情况、相对位置语义和控制响应需实车验证，程序发出命令不等于已证明机械连续。

## 参数在哪调

| 参数 | 当前值 | 修改位置/作用 |
|---|---|---|
| 前直行 | 11500*4-16998 = 29002 | task.c 中 car(13) 的第三参数，增大通常延后转弯位置 |
| 内侧附加行程 | 2225*4 = 8900 | car.h：CAR_DIR13_INNER_PULSES，影响短程轮结束位置和转弯位置 |
| 转向量 | 90.0° | car.h：CAR_DIR13_TURN_DEG，增大转得更多，减小提前衔接后直行 |
| 后直行 | 11750*4-2*16998 = 13004 | car.h：CAR_DIR13_AFTER_PULSES，增大转弯后走得更远 |
| 速度 | speed，当前500 | car(13) 第二参数，支持1～500；四轮使用相同输入速度 |

dir13 的转弯由角度判断，**不使用 dir10/12 的外侧 9000*4**。修改 dir10 或 dir12 的 9000 不会影响 dir13。16998 沿用此前试车补偿基准，尚未因新轨迹重新标定。参数只影响新模式；应先调转向量，再调前后直行位置。

转向量是相对进入 dir13 时的朝向，并非固定世界坐标 -90°。当前第一处进入前仍有原 `car(0,0,0)`，所以初始方向应接近 0°。中间取消调正后，也不保证后段一直保持绝对 -90°，控制/通信滞后与惯性会造成转向过冲。

## 持续运动的停止条件

2、4 号轮的速度命令没有自身距离终点，必须给它停止边界。只为 dir13 加最小的断帧/超时停止：无有效陀螺仪帧、断帧超过 500 ms、转向超时、后直行超时或收到电机错误时停止四轮并保持，复位后重试。运动阶段时间上限为 `12000*500/speed` ms，前转弯和后直行分别计时。

Keil/OLED 可查看现有 car_debug_mode=13；另可查看：

- car13_phase：1=前直行/转弯，2=后直行，3=完成，255=停止。
- car13_error：0=无错误，1=参数无效或从未收到有效陀螺仪帧，2=陀螺仪断帧，3=转弯超时，4=后直行超时，5=电机错误（具体地址/错误码见现有 wheel_reply_error_addr/code）。

这些条件不查询驱动器状态，不是之前让 dir10 卡在启动前的 3A/位置到位检查。
