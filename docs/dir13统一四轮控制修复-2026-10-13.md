# dir13 统一四轮控制修复（2026-10-13）

用户实车反馈 dir13 在转弯过程中乱飘。此前实现把1、3号轮设为位置模式、2、4号轮设为持续速度模式，两侧的减速和结束条件不一致；实车根因没有通过记录测量完全确认，但该控制结构已移除。本次只修复 dir13，不将此前复制同类结构的未发布 dir14/15 草稿一同发布。草稿及修改前完整工程字节保存于 D盘 `.local/dir13-fix-20261013/`，后续另行继续。

当前调用仍是：

```c
car(13,speed,11500*4-CAR_ARC_90_TRIM_PULSES);
```

前段、转弯角度和后段的参数数值保留：前段29002脉冲、90°、后段13004脉冲。现阶段三步如下：

1. **前直行四轮都用速度模式。**四轮同速、同加速度150。读1号轮实际位置，以开始前的位置为基准测量实际转动量，达到第三参数 location 后进入转弯。第三参数现在就是前段测量行程，不再额外加旧版的2225*4。
2. **转弯四轮仍都用速度模式。**内侧1/3号、外侧2/4号保持 `2225:9000` 的目标速度比例；speed=500时目标速度分别为123/500 RPM。转弯速度变化的加速度参数为235，使内侧轮减速至转弯速度；没有单侧位置终点。使用现有 anglea 累加同dir6方向的转向量，处理±180°跨界，达到90°后退出。
3. **保留用户加的停止和100ms稳定等待。**四条停止命令之间补齐正常10ms发送间隔。随后四轮统一改为后段位置运动，方向和后段脉冲不变，加速度从0改回150，避免从停止状态直接全速启动。等项目已有四轮FD到位记录完整后返回。

这次保留用户当前的停止100ms逻辑，未声称完全不停的三段运动。转弯结束后主流程还会等100ms，再执行下一处car10，这是下一次转弯，不是重复后直行。

## 位置反馈协议

使用当前工程 Emm_V5 接口发送 `01 36 6B`（S_CPOS），解析8字节 `01 36 符号 数据4字节 6B`，符号0/1表示正/负。由原有UART完整帧FIFO读取，扫描掉前面的无关回包；临界区保证读取快照期间不会被中断改写。不修改UART代码，不使用此前导致阻塞疑虑的3A状态查询。

Emm位置数据每圈65536计数；默认1.8°、16细分的串口位置脉冲每圈3200。因此按：

`abs(当前位置-起始位置) × 3200 >= location × 65536`

判断前段结束，使用64位整数避免溢出。3200留作 `CAR_DIR13_PULSES_PER_REV` 配置；如果实际驱动器串口脉冲单位不同，需按实机调整。协议依据仓库 `reference/manuals/ZDT_X42S第二代闭环步进电机用户手册V1.0.5.pdf` 第57、72页的Emm位置单位及实时位置回包说明。未确认实机固件细节前，不能把协议模拟当作实机证明。

## 参数位置

全部在BSP/car.h，前段在task.c调用第三参数：

| 参数 | 当前值 | 作用 |
|---|---:|---|
| car(13)第三参数 | 29002 | 前段实际测量距离；增大通常更晚开始转弯 |
| CAR_DIR13_INNER_PULSES / OUTER_PULSES | 8900 / 36000 | 仅用作转弯目标速度比例，不是转弯阶段的实际脉冲终点 |
| CAR_DIR13_TURN_DEG | 90.0 | 转向量，相对进入转弯阶段时的角度 |
| CAR_DIR13_AFTER_PULSES | 13004 | 后段位置运动距离 |
| CAR_DIR13_TURN_ACC | 235 | 转弯时速度变化的加速度档位 |
| CAR_DIR13_EXIT_SETTLE_MS | 100 | 用户原有转弯出口稳定等待 |
| CAR_DIR13_PULSES_PER_REV | 3200 | 位置反馈与串口位置脉冲的单位换算 |

这不是复现旧轨迹逐点位置：旧版初始内侧位置指令包含附加行程并提前减速，新版前段按实际location切换，弯道也改为速度比例控制；转弯起点、弯道半径和实际终点需要重新试车调距。16998补偿基准没有自动重算。改变速度比例会影响转弯形状；90°角度由TURN_DEG调整，不能继续把OUTER_PULSES当作角度脉冲终点。

## 故障与阶段

car13_phase：1前直行、2转弯、3后直行、4完成、255停止。

car13_error：0正常；1参数无效/未收到有效陀螺仪帧；2陀螺仪断帧；3前段或转弯超时；4后直行超时；5电机返回错误；6实时位置回包失败。位置请求单次100ms、最多3次；位置失败时停止而非继续无界速度运动。gyro断帧500ms停止，各运动阶段超时为12000*500/speed毫秒。停止后保持，复位重试。
